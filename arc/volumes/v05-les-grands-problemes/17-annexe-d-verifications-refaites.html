Annexe D. Vérifications refaites

Toutes les vérifications ci-dessous ont été refaites pour ce volume par le script verif.py (Python 3, fractions, numpy, scipy), exécuté le 15 octobre 2026 ; toutes passent. Les calculs sur π et sur les polynômes sont exacts (fractions) ; ceux sur ζ sont numériques en double précision.

π (chapitre 2). - Fraction continue de π, douze quotients [3; 7, 15, 1, 292, 1, 1, 1, 2, 1, 3, 1], identiques sur les deux bornes d’un encadrement de π à 10⁻⁷⁵ ; réduites 22/7, 333/106, 355/113, 103 993/33 102. - Archimède : 223/71 < π < 22/7, exact. - Dalzell : quotient x⁶ − 4x⁵ + 5x⁴ − 4x² + 4 et reste −4 en fractions exactes ; aire du quotient 22/7 ; aire de x⁴(1 − x)⁴ égale à 1/630 = 4! 4!/9! ; 22/7 − π = 0,0012644892673, entre 1/1260 et 1/630. - Lucas : quotient d’aire 355/113, reste −4 ; écart 2,6676 × 10⁻⁷. - Invariance de x⁴(1 − x)⁴ sous x ↦ 1 − x, coefficient par coefficient ; maximum 1/256 en ½.

ζ (chapitres 3 et 4). - |ζ(ρ₁)| = 3,9 × 10⁻¹⁵. - Euler à σ = 1,1, 0 ≤ t ≤ 200 : min |ζ| = 0,3769 > ζ(2,2)/ζ(1,1) = 0,1408. - |Sₙ(ρ₁)| = 2,24 ; 22,36 ; 70,70 ; 223,58 pour N = 10³, 10⁵, 10⁶, 10⁷ ; |1 − ρ₁| = 14,14. - Écart somme moins aire en N = 10⁷ : 1,581 × 10⁻⁴, conforme à 1/(2√N) ; après le demi-terme : 3,72 × 10⁻¹¹. - Corollaire du zéro : 1/(ρ₁ − 1) et ∫₁^∞ {x} x^{−ρ₁−1} dx égaux à 2,6 × 10⁻¹² près (la source donnait 3 × 10⁻¹²). Formule d’Abel en s = 2 : π²/6. - Hermite : π²/6 en s = 2 ; |ζ(ρ₁)| par Hermite 8,4 × 10⁻¹⁵ (la source donnait 4,5 × 10⁻¹², selon la quadrature) ; part du continu ½ + 1/(ρ₁ − 1) = 0,4975 − 0,0707 i. - Porte (iii) : η(2) = π²/12. |1 − 2^{1−ρ₁}| = 2,37 ; |1 − 2^{1−s}| ≥ 2^{1−σ} − 1 > 0 sur une grille de la bande. - Produits partiels d’Euler en ρ₁ sur les premiers jusqu’à 2 × 10⁶ : module entre 9,4 × 10⁻⁵ et 18,76, sans limite ; min |1 − p^{−ρ₁}| = 0,806 pour p ≤ 2 × 10⁵. - Λ réelle sur la droite : |Im/Re| ≤ 8,6 × 10⁻¹⁴ ; à σ = 0,7, ≥ 0,13 ; Λ(0,3 + 2i) = Λ(0,7 − 2i) à 10⁻¹². - ζ(½) = −1,46035 ; ζ(σ) < 0 pour σ de 0,01 à 0,99. - Mertens à 10⁶ : A = 304 069, B = 303 857, A + B = 607 926, 6N/π² arrondi à 607 927, M = 212 ; A(10) = 3, B(10) = 4 ; max |M|/√N = 0,89, atteint en N = 5. - Lagarias de 2 à 100 000 : aucune violation, marge minimale 1,14 % en n = 12. - Jacobi en x = 0,5 et 1,7 à 10⁻¹² ; ∫ e^{−4πx} x^{1/2} dx = Γ(3/2) π^{−3/2}/8 = 0,0198943679. - 2n = n² seulement en n = 2 (jusqu’à 10 000) ; DR(x²) = DR((9 − x)²) pour x = 1 à 8, quatre racines ; 2x − 9 ne s’annule qu’en 4,5.

Produit d’Euler (chapitre 5). - Produit déplié sur les premiers jusqu’à 2000 : chaque entier de 1 à 2000 sort exactement une fois. - Produit pour s = 2 sur les premiers < 2 × 10⁵ : 1,6449334415, à moins de 10⁻⁶ de π²/6. - Axe π²/54, rails 4π²/27, grille π²/9 (sommes jusqu’à 10⁶) ; multiples de 3 = racines 3, 6, 9 et « ni pair ni multiple de 3 » = 6k ± 1, jusqu’à 100 000. - Les quatre familles de composés de la grille, pour k de 1 à 20 000 ; 35 = 6 × 6 − 1, première rencontre de 5 et 7. - Briques 2 et 3 alternées : absents de 1 à 30 exactement {1, 4}.

Yang-Mills (chapitre 10). - DR(n) + DR(n² − 1) ∈ {5, 10, 11, 14, 17} pour 2 ≤ n ≤ 10⁶ ; table des neuf classes. - SO(n) et Sp(n) : S = 9 exactement quand DR(n) = 8, avec DR(dim) = 1, pour n ≤ 10 000 (la source s’arrêtait à 81). - Exceptionnels : S = 7, 11, 12, 14, 13. Modèle standard : 2 + 5 + 11 = 18 ; rangs 6 ; dimensions 12, de racine 3 ; produit 24. - Test d’unicité : 11 triples sur 84, dont (1, 2, 3) le premier ; la liste complète est donnée en [10.21]. - p² − 1 divisible par 24 pour tout premier 5 ≤ p < 10⁵ ; 496 parfait.

Navier-Stokes (chapitre 9). - Loi d’échelle : 1 + a = 3 donne a = 2 ; noyau de la chaleur G(λx, λ²t) = λ⁻³ G(x, t) à 10⁻¹⁵. - p* = 6 en d = 3, 4 en d = 4 ; 3/2 − 1 = ½. - Pivot : 4,5 est le seul pivot qui ferme. - Précision : les bases b ≤ 5000 qui satisfont b − 2 puissance de 2, b − 1 composé, b + 1 premier et b pair sont 10, 66, 130, 4098 ; avec la clôture carrée b − 1 = p², seule 10 reste (balayage jusqu’à 10⁷, et démonstration générale, Volume 2, É 3.3) (annexe B.4.2). - Correction : le pli universel DR(ak) + DR((9 − a)k) = 9 vaut pour a ∈ {1, 2, 4, 5, 7, 8} et k = 1 à 8 ; pour la paire (3, 6), les colonnes × 3 et × 6 donnent 18 (annexe B.4.2). - −(ln 2 + 2) = −2,693 ; (½)^{ln x} = x^{−ln 2} ; la valeur attendue de |cos θ| sur la sphère vaut ½ ; 4π R² × ½ × 2R/3 = (4/3)πR³.

P contre NP (chapitres 7 et 8). - 3 ne divise aucun 2ᵏ, k ≤ 200 ; pré-image de 0 de x₁ ∧ x₂ : 3 × 2^{n−2}, jamais puissance de 2, n = 2 à 20 ; les sous-espaces de (ℤ/2ℤ)⁴ ont pour cardinaux {1, 2, 4, 8, 16}. - Lemme de la partition : 2ᵃ + 2ᵇ = 2ⁿ impose a = b = n − 1 (n ≤ 30). - 9! = 362 880, log₂ 9! = 18,47 ; × k bijectif sur les neuf positions exactement pour k = 1, 2, 4, 5, 7, 8. - Produits consécutifs : racines {2, 3, 6, 9} pour k = 2, {3, 6, 9} pour k = 3 à 5, {9} pour k ≥ 6 (n < 5000). - Tours de 1/3 : 0, 0, 1, 2, 5, 10, 21, 42, 85 ; remontée sans reste. Pli de 1/1 000 003 : 4000 bits, 1952 uns (écart de 2,4 % à l’équilibre), égaux à l’écriture de ⌊2⁴⁰⁰⁰/1 000 003⌋. - Compte de Shannon pour n = 20 : avec la majoration (16 (n + s)²)ˢ du nombre de circuits, s = 30 985 est la plus grande taille insuffisante. - a + b + c = 2 maj + min sur les 8 triplets ; a + b = 2(a ∧ b) + (a ⊕ b) = (a ∨ b) + (a ∧ b) sur les 4 couples. - Relations sans pôles : arité 3, 24 / 24 / 0 / 15 sur 63 ; arité 4, 168 / 1472 / 21 / 14 722 sur 16 383, dont 4 par le ET et 4 par le OU ; frontière en arité 4, 15 565 relations sans position figée, 34 / 1068 / 13 / 14 450, aucune par le ET ou le OU. - 1-dans-3 : comptes 0 à 3 portés par 1, 3, 3, 1 configurations. - Trios par programmation linéaire : fractionnaire 3/2, prix 3/2, entier 1 ; après sacrifice, 1 = 1. Anneaux de 3 à 11 trios : fractionnaire r + ½, entier r ; après un retrait, r = r. Couplage biparti : fractionnaire égal à l’entier sur 60 instances. - Cadre : 4(n − 1) = n(n − 1)/2 seulement pour n = 8 (2 ≤ n ≤ 99) ; 28 + 36 = 64 ; C(8, 2) = 28.

Popper (chapitre 11). - Fibonacci en racines : 81 états, pas bijectif, période 24 depuis (1, 1). - Collatz : 3 et 7 se rejoignent en 10 par le chemin 22, 11, 34, 17, 52, 26, 13, 40, 20. - Tiroirs : sur les 81 placements de 4 marcheurs sur 3 cases, deux marcheurs partagent toujours une case. - Goldbach : tout pair de 4 à 10 000 est somme de deux premiers.

Non refaits ici, et repris des pièces sources avec leur reçu : la largeur de résolution des 200 instances 2-CNF, l’accord du graphe d’implication de 2-SAT avec la force brute sur 300 instances, les 295 instances bipartites de la pièce source, la vérification de la formule d’Abel en s = 0,3 + 2i, et l’injectivité de l’adresse jusqu’à 10⁵ (immédiate par la division).
